# Estatística básica
 Este repositório tem como objetivo reunir alguns exercícios que realizei durante meus estudos de Estatística básica.

Observação: alguns exercícios foram realizados na plataforma Khan Academy. Por esse motivo, optei por apresentar o print da tela do exercício ou uma foto capturada pelo celular como forma de registro.

## Assuntos

- Análise de uma variável categórica
- Tabelas de contingência
- Distribuições em tabela de contingência
